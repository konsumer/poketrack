Syntakt WCLAP maker

The Syntakt's 11 digital machines as a poketrack instrument, made from your own Syntakt OS file.

  1. Download the Syntakt OS from elektron.se and unzip it. You need Syntakt_OS1.42.syx (1.41 works too).
  2. Pick that file below. It's read here in your browser, and nothing is uploaded.
  3. Save syntakt.wclap.wasm and point a PLUGIN unit at it in poketrack.

Save syntakt.wclap.wasm
The plugin you make contains Elektron's code from your OS file, so it's for your own use. If you share a song that uses it, leave syntakt.wclap.wasm out: whoever gets the song can make their own here.

BD MODERN, SD BASIC, CY ALLOY, PC CARBON, SY TONE, SY CHORD, SD VINTAGE, CP VINTAGE, SY TOY, SY BITS and SY SWARM. The Syntakt's other machines are analog circuits, so there's no code to run.
