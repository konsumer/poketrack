PokeTrack Examples
==================

This is bonus content for PokeTrack (https://store.steampowered.com/app/5043200).
Nothing here needs to be "run" - just copy whatever you want into PokeTrack's
own folders (or point PokeTrack's file browser at this folder directly).

What's included:

  beats/     - drum pattern kits (breaks, house, hip-hop, DnB, and more),
               organized by genre, ready to drop into the pattern editor.
  *.rpt      - full demo songs (hello.rpt, muscle-pigeon.rpt) you can load
               and pick apart to see how a finished track is put together.
  *.sf2      - a General MIDI soundfont (microgm.sf2) for the SF2 instrument
               unit.
  themes/    - alternate UI color themes (.ptt), including converted LGPT
               themes.
  plugins/   - example WCLAP plugins (.wclap.wasm) showing what's possible
               with custom CLAP-compiled-to-wasm instruments and effects.

Source and docs: https://github.com/konsumer/poketrack
